## 0. 前馈是什么

PID 只在出现误差后才出力，天生滞后。前馈是按"模型/目标"直接给出一部分控制量，让 PID 只补残差：

- **重力矩前馈**：按目标俯仰角算出电机该出的静力矩 `t_ff`，重力不再制造稳态误差。
- **速度前馈**：对目标位置微分出 `v_des`，快速运动时提前注入速度项，减小跟踪滞后。
- **底盘跟随前馈**：云台在世界系里转，底盘按同一角速度提前转，而不是等角度误差出现再追。

本工程 J4310 用达妙 MIT 协议：帧里本来就有 `p_des / v_des / t_ff` 三个通道，前馈直接送电机，MCU 不加环。

## 2. 第一轮：俯仰重力矩 + 速度前馈

插入点选 **方案 B：全部放 `motor.c` 的 `DM_update`**（现为空函数 `motor.c:200`），`gimbal_task.c` 零改动。依据：`set_target` 写入的 `_p_des`（`motor.c:327`）即目标俯仰角，`_v_des`/`_t_ff`（`:330/:333`）J4310 路径无人使用，由 `DM_update` 每拍接管。

### 2.1 改动 1：宏区（`motor.c:58` 之后）

```c
/* ---- 俯仰前馈（第一轮联调） ---- */
#define PIT_GRAV_FF_GAIN_NM    1.0f   /* 重力矩前馈增益 (N·m)；0=关闭；符号台架标定 */
#define PIT_GRAV_FF_OFFSET_RAD 0.0f   /* 重力相位补偿 (rad)，由 IMU pitch 零位决定 */
#define PIT_V_FF_ALPHA         0.3f   /* 速度前馈一阶滤波系数；0=关闭速度前馈 */
#define PIT_V_FF_SLEW_RAD_S    3.0f   /* v_des 限幅 (rad/s)，与 kd=2 合计 ≈6 N·m 上限 */
#define PIT_V_FF_JUMP_RAD      0.02f  /* 目标跳变吸收阈值 (rad) */
#define PIT_V_FF_GAP_MS        50U    /* 断档判据 (ms) */
```

阈值 0.02 的依据：正常单拍目标步长 = 摇杆满杆 `RC_PIT_SENS=0.005` rad（`gimbal_task.c:18`）、鼠标极限 ≈0.013 rad（`MOUSE_PIT_SENS=0.00005`，`:16`）；重使能跳变通常 ≥0.05 rad。0.02 在正常之上留裕量、在跳变之下可靠截获。

### 2.2 改动 2：`struct DM_MIT_data`（`motor.c:49` `enable_requested` 之后）

```c
    /* 速度前馈状态（DM_update 每拍维护） */
    float _v_ff_lpf;
    float _ff_last_p;
    uint32_t _ff_last_tick;
```

### 2.3 改动 3：`DM_update` 实现（替换 `motor.c:200-203`）

```c
void DM_update(struct motor_device *motor)
{
    if (motor == NULL || motor->motor_data == NULL) return;
    struct DM_MIT_data *d = (struct DM_MIT_data *)motor->motor_data;

    /* 失能：清前馈状态，防重使能带病启动 */
    if (d->enable_requested == 0U) {
        d->_t_ff = 0.0f;
        d->_v_des = 0.0f;
        d->_v_ff_lpf = 0.0f;
        d->_ff_last_tick = 0U;
        return;
    }

    /* 位置异常（NaN/Inf）：前馈清零 */
    if (!isfinite(d->_p_des)) {
        d->_t_ff = 0.0f;
        d->_v_des = 0.0f;
        d->_v_ff_lpf = 0.0f;
        d->_ff_last_tick = 0U;
        return;
    }

    const uint32_t now = osKernelSysTick();

    if (d->_ff_last_tick == 0U || (now - d->_ff_last_tick) > PIT_V_FF_GAP_MS) {
        /* 首拍/断档（>50ms，含故障恢复）：清状态重新预热，不做微分 */
        d->_ff_last_p = d->_p_des;
        d->_ff_last_tick = now;
        d->_v_ff_lpf = 0.0f;
    } else {
        float dp = d->_p_des - d->_ff_last_p;
        /* 跳变吸收：重使能/模式切换的阶跃不算微分 */
        if (fabsf(dp) <= PIT_V_FF_JUMP_RAD) {
            const float dt_s = (float)(now - d->_ff_last_tick) * 0.001f;
            if (dt_s > 0.0f) {
                const float v_raw = dp / dt_s;
                d->_v_ff_lpf += PIT_V_FF_ALPHA * (v_raw - d->_v_ff_lpf);
                if (d->_v_ff_lpf >  PIT_V_FF_SLEW_RAD_S) d->_v_ff_lpf =  PIT_V_FF_SLEW_RAD_S;
                if (d->_v_ff_lpf < -PIT_V_FF_SLEW_RAD_S) d->_v_ff_lpf = -PIT_V_FF_SLEW_RAD_S;
            }
        }
        d->_ff_last_p = d->_p_des;
        d->_ff_last_tick = now;
    }

    d->_v_des = d->_v_ff_lpf;   /* v_des 所有权：本函数微分生成 */
    d->_t_ff  = PIT_GRAV_FF_GAIN_NM * cosf(d->_p_des + PIT_GRAV_FF_OFFSET_RAD);
}
```

双保险防尖峰：断档/首拍预热（`_ff_last_tick=0`）+ 跳变吸收（`>0.02`）。重使能瞬间 `_p_des` 可能跳数 rad，若直接微分 `kd=2 × 3 rad/s ≈ 6 N·m`。

### 2.5 分两小轮上

`PIT_V_FF_ALPHA=0` 时 LPF 恒 0 → `_v_des=0` → 速度前馈天然关闭，不需要新宏。

| 小轮 | 参数状态 | 验证内容 |
|---|---|---|
| 1a | `GAIN=1.0`，`ALPHA=0` | 重力前馈符号与幅值 |
| 1b | `GAIN` 已标定，`ALPHA=0.3` | 速度前馈跟随性；**标定完 α 需复查**（控制链变了，微分输入的统计特性跟着变） |

### 2.6 标定步骤

前提：Round 0 全绿、固件已烧录。

1. **零位检查**：云台水平放置，读 `robot_ctrl.gimbal.pitch`（`sensor_task.c:79`，`ins_angle[2]`）。
   - ≈0 → 用 `cos`（公式现状）
   - ≈±π/2 → `PIT_GRAV_FF_OFFSET_RAD = ∓π/2`（`cos(x±π/2)=∓sin x`，等效换轴）
2. **基线**：`GAIN=0, ALPHA=0`，记录各角度手松云台的自然状态。
3. **符号**：`GAIN=1.0` 短时使能，手扶水平后释放——正确 = 保持不坠（甚至略顶）；坠落或反向顶 = 符号错，先回 0 再改 `GAIN=-1.0`。
4. **幅值**：多角度（水平/±45°）读 `get_status "T"`（Round 0 已修），与基线比误差，收敛 `GAIN`；预期 |GAIN| 量级 1~3。
5. **1b 速度前馈**：`ALPHA=0.3`，快速甩动鼠标/摇杆看目标跟随，无高频抖动、无啸叫；异常先回 `ALPHA=0`，不动 `kd`（`kd` 同时放大阻尼与 `v_des` 注入，是联调笔记项，不进本轮代码）。

## 3. 第二轮：底盘三件套

### 3.1 2a：跟随前馈（`chassis_task.c:466`）

单位链（已核实）：`yaw_v = gyro[2]`，`BMI088_GYRO_2000_SEN = 0.0010653 = (2000°/s → rad/s)/32768`（`BMI088driver.h:9`）→ **`yaw_v` 单位是 rad/s**。不要乘 `0.01745`（会小 57 倍），也不要除 `CHASSIS_MAX_RAD`：

```c
#define FOLLOW_FF_GAIN  0.05f   /* 跟随前馈增益 (归一化 per rad/s)；0=关闭；台架标定 */

/* chassis_task.c:464-467 */
} else {
    /* 正常跟随：P 反馈 + 云台角速度前馈 */
    vw_final = -angle_error * FOLLOW_P_GAIN
             + FOLLOW_FF_GAIN * robot_ctrl.gimbal.yaw_v;
}
```

`CHASSIS_MAX_RAD=60`（`chassis_task.c:23`）**不是 rad/s→归一化系数**：M3508 经 19.2:1 后轮速 ≤49 rad/s，底盘世界角速度物理上限 ≤12 rad/s，60 rad/s=3438°/s 不可能。它只是既有 `yaw_speed` 链（`:481`）的电压缩放经验值，保持不动。

`FOLLOW_FF_GAIN` 的物理意义 = **1 / 底盘满速世界角速度**（实测标定，预期收敛 0.08~0.17）。标定：0.05 → 0.1 → 0.15 逐步加，判据 = 跟随滞后消失、云台不来回摆；反向甩 = 符号反。换车按满速角速度重算，不盲搬。

两个注意：

- 插入点在斜坡（`:474`）之前，前馈阶跃会被斜坡整形——是好事。
- `vw_final` 经 `:481` 流入既有 `yaw_speed` → 云台侧链路：按 `ff=0.05×1rad/s` 估算，云台电压增量 ≈1800/25000 ≈7%，可忽略；首测仍观察云台有无多余动作，有则把前馈挪到 `:481` 之后单独接轮速。

### 3.2 2b：积分分离 + `Ki=0.1`

`motor.c:543` 无条件累加积分，目标跳变时积分暴增导致过冲。先加分离，再开 `Ki`：

```c
/* motor.c 宏区 */
#define M3508_I_SEP_RPM  1000.0f   /* 积分分离阈值 (rpm)：|误差|≥阈值暂停积分 */

/* motor.c:542-543 */
/* 3. 积分项 (I) — 积分分离 */
if (fabsf((float)error) < M3508_I_SEP_RPM) {
    d->_i_term += d->_ki * (float)error;
}
```

- `Ki=0` 时分离零影响 → 可以先合码、再调参。
- 底盘 M3508 `Ki` 0 → 0.1（`All_Motors_Init`，`motor.c:1386` 区）；上限仍 `i_max=2000`。0.1 稳了再考虑往 0.3 走。
- 分离只做单阈值，不做变积分两档（够用且简单）。

### 3.3 2c：起步斜坡

`CHASSIS_VW_ACCEL_UP`（`chassis_task.c:44`）2.5 → **3.5** → 4.0 → 5.0 分步验证手感，一次只动一档。与 DOWN 不对称的问题在手感确认后再议。
